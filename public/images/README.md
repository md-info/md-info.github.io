# Toronto night backgrounds

These are real Toronto photographs, downloaded at 2400px width for the portfolio background sequence.

- `toronto-waterfront.jpg`: Mike Swigunski, [Toronto skyline at night](https://unsplash.com/photos/pFR9lF9LuN8).
- `toronto-aerial.jpg`: alex°, [Walking up the CN Tower at nighttime](https://unsplash.com/photos/CamJb_3RDoM).

Both photographs are provided under the [Unsplash License](https://unsplash.com/license). Attribution is also available in the website's Settings screen.

Background movement is CSS panning and crossfading between photographs, with a light rain overlay. These are not video clips or game screenshots.
